How to Install ShypDirect Pro by Roddy Technologies
Follow these simple steps to install ShypDirect Pro on any hosting account that supports PHP & MySQL:

✅ Requirements
Before you begin, ensure your hosting has:

PHP 8.1 or higher

MySQL 5.7 or higher



🧾 Step-by-Step Installation
1. Upload the Script
Login to your cPanel.

Open File Manager.

Navigate to the public_html/ folder (or your subdomain folder).

Upload the ShypDirect Pro.zip file and extract it.

2. Create a Database
Go to MySQL® Databases in cPanel.

Create a new database, username, and assign the user to the database with All Privileges.

Save the DB name, username, and password.

3. Configure .env File
In the extracted folder, locate the .env file.

Edit the .env file with your database details:

APP_NAME="ShypDirect Pro"
APP_URL=http://yourdomain.com

DB_HOST=localhost
DB_DATABASE=your_db_name
DB_USERNAME=your_db_user
DB_PASSWORD=your_db_password

Site will be up after configuration.
